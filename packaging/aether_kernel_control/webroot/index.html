💡 Comprehensive Knowledge Base In-Depth Tuning Guide

❓ AETHER Help Center & Hardware Tuning Reference

Complete guide to every kernel setting on Redmi Note 10: what it does, what happens when you increase or decrease it, and recommended values.

⚡ Kryo 460 CPU Max Frequencies (Little & Big Clusters)
What it does: Sets the peak clock limits for the 6× Silver efficiency cores (0-5) and 2× Gold high-performance cores (6-7).
⬆️ If Increased (e.g. Little 1804 MHz / Big 2208 MHz)

Benefits: Instant app launch speeds, buttery 60 FPS animations, and maximum gaming frame rates under sustained load.

Drawbacks: Higher peak power consumption and elevated temperatures during heavy prolonged gaming.

⬇️ If Decreased (e.g. Little 1017 MHz / Big 1209 MHz)

Benefits: Drastic battery savings (+3 to +5 hours SOT in Ultra Saver mode), device stays ice-cold, zero thermal throttling.

Drawbacks: Heavy games (BGMI, Genshin) and video rendering will take longer or drop frames.

💡 Real-World Example & Recommended Value
Daily Driver: Little 1497 MHz + Big 1843 MHz (silky UI, great battery).
Competitive Gaming: Little 1804 MHz + Big 2208 MHz (Performance mode peak).
Emergency Low Battery: Little 1017 MHz + Big 1209 MHz (Ultra Battery Saver).
⏱️ Schedutil Rate Limits (up_rate_limit & down_rate_limit)
What it does: Controls how many microseconds the kernel waits before ramping CPU clocks up when load arrives, and dropping clocks down when load finishes.
⬆️ If Increased (e.g. up_rate_limit: 2000 μs)

Benefits: Prevents CPU from spiking up for brief background tasks; saves battery during casual reading and video playback.

Drawbacks: Sluggish UI ramp-up; app switches may feel slightly delayed.

⬇️ If Decreased (e.g. up_rate_limit: 0 μs)

Benefits: Immediate clock jump on frame render; completely eliminates scroll hitching and frame drops.

Drawbacks: Slightly higher battery consumption during sporadic touch interactions.

💡 Real-World Example & Recommended Value
Gaming / Smooth: 0 μs up-rate (zero micro-stutter).
Balanced Daily: 500 μs up-rate, 500 μs down-rate.
Battery Saver: 2000 μs up-rate, 500 μs down-rate.
🖐️ CPU Touch Input Boost (Duration & Frequency)
What it does: Fires an instantaneous CPU clock boost the millisecond your finger touches the glass to prepare the compositor for scrolling.
⬆️ If Increased (e.g. 80-120 ms duration)

Benefits: Ultra-responsive touch velocity and fluid scrolling through heavy apps like Instagram, Twitter, and Reddit feeds.

Drawbacks: Typing rapidly on keyboard repeatedly wakes high-power cores, increasing battery drain.

⬇️ If Decreased (e.g. 0-20 ms duration)

Benefits: Significant battery endurance savings; prevents CPU wakeup during screen taps.

Drawbacks: Fast flicks in long web pages may feel slightly stiffer or drop initial frames.

💡 Real-World Example & Recommended Value
Stock Balanced: 80 ms (Little 1017 MHz / Big 1209 MHz).
Ultra Battery: 0 ms (Disabled) for extreme power saving.
🎮 Adreno 612 GPU Governor & Minimum Clock Floor
What it does: Sets the base frequency floor (180 to 845 MHz) and power collapse idle timer for the Qualcomm Adreno 612 GPU.
⬆️ If Increased (Floor: 355 MHz / 504 MHz)

Benefits: Keeps GPU execution pipelines primed; eliminates frame drops during heavy 3D action, smoke grenades, and explosions in BGMI.

Drawbacks: Higher idle power consumption while the screen is awake.

⬇️ If Decreased (Floor: 180 MHz)

Benefits: Maximum power efficiency when reading articles, viewing static photos, or chatting.

Drawbacks: GPU takes 40ms to ramp up when a 3D animation begins, causing a brief frame hitch.

💡 Real-World Example & Recommended Value
BGMI / Call of Duty: 504 MHz lock with 120ms idle delay (locked 60 FPS).
Daily / Smooth: 180 MHz floor with 64ms idle delay.
🔋 Hardware Battery Charge Protection & Instant Bypass
What it does: Controls the Qualcomm SMB5 charging IC to pause electric current into lithium cells at 80%, 85%, 90%, or 95% while keeping USB power alive.
Mode 1: USB-Powered Hold

Motherboard runs directly off USB wall charger; battery charging is halted at 0mA. Device stays cool, battery cycle wear is 100% eliminated.

Mode 2: Idle Float

Charger stops current, lets battery drain 3%, and pulses a top-off. Ideal for desk charging without wall power hold.

💡 Real-World Scenario: Overnight Charging & Car Hotspot
Leaving phone on charger overnight at 100% causes chemical battery degradation. Setting 80% Cutoff with USB Hold extends battery life from 2 years to 5+ years without battery swelling.

Instant Bypass Active (0mA)

🧠 BORE (Burst-Oriented Response Enhancer) CFS Scheduler
What it does: Enhances standard Linux CFS by analyzing task burstiness. Prioritizes interactive UI tasks over heavy background batch processes.
⬆️ If Increased (Scale: 1380 - 1536)

Benefits: Foreground apps get top priority; UI stays silky-smooth even while downloading games or updating 20 apps in Play Store.

Drawbacks: Heavy background video encoding or file unzipping will progress slightly slower.

⬇️ If Decreased (Scale: 1024 / Disabled)

Benefits: Standard Linux round-robin scheduling; background batch jobs finish faster.

Drawbacks: Foreground UI may stutter if a heavy background task hogs the CPU.

💡 Real-World Example & Recommended Value
Scale 1380 (Default): Tuned specifically for mobile app switching and zero touch latency.
📁 UFS 2.2 Storage Read-Ahead & Google Kyber I/O
What it does: Sets sequential flash storage lookahead read cache and enables Google Kyber I/O latency queue scheduling.
⬆️ If Increased (512 KB - 1024 KB)

Benefits: Accelerates app loading times (Instagram, WhatsApp, games) by up to 30% by pre-fetching storage blocks.

Drawbacks: Uses a fraction more RAM buffer space for read queues.

⬇️ If Decreased (128 KB)

Benefits: Conserves RAM buffer space; ideal for extreme battery saving.

Drawbacks: Game launch screens and loading maps will take slightly longer.

💡 Recommended Value
512 KB with Google Kyber: The sweet spot for Redmi Note 10 UFS 2.2 flash storage.
💾 ZRAM Memory Compression & VM Swappiness
What it does: Compresses background app memory pages into physical RAM using high-speed LZ4 SIMD compression.
⬆️ If Increased (Swappiness: 100 - 160)

Benefits: Keeps 15-20 apps alive in memory without Android killing them. App switching is instant with zero reloading.

Drawbacks: Slight CPU cycle consumption during memory compression.

⬇️ If Decreased (Swappiness: 60)

Benefits: Minimum CPU compression overhead; best for battery endurance in emergency situations.

Drawbacks: Background apps reload more frequently when opening multiple heavy apps.

💡 Recommended Configuration
Swappiness 100 with 3.0 GB LZ4 ZRAM: Provides desktop-grade multitasking without thrashing.
🌊 Multi-Gen LRU (MGLRU) & min_ttl_ms
What it does: Linux kernel next-generation memory management that separates pages into generations based on access frequency.
⬆️ If Increased (min_ttl_ms: 2000 - 4000 ms)

Benefits: Strongly protects active apps from being paged out; prevents browser tab reloads in Chrome.

Drawbacks: Keeps memory occupied longer before freeing.

⬇️ If Decreased (min_ttl_ms: 0 - 500 ms)

Benefits: Quickly maximizes the free memory pool.

Drawbacks: Frequently switched apps may need to reload from flash.

💡 Recommended Value
1000 ms: Balanced working-set retention for smooth daily multitasking.
